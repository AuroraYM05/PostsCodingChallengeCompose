# Post Coding Challenge Compose

## Descripción

Aplicación en Android que obtiene y muestra publicaciones consumidas de una API.

Funcionalidades:

* Consulta publicaciones desde una API.
* Visualiza las publicaciones en una vista.
* Compatibilidad de modos de pantalla oscuro y claro

## Tecnologías

- Kotlin
- Jetpack Compose
- Retrofit
- OkHttp
- Moshi
- Hilt
- Coroutines
- Navigation Compose

## Arquitectura

- Clean Arquitecture
- MVVM (Modelo - Vista - ViewModel)

## API

Link DummyJson: (https://dummyjson.com/posts)
